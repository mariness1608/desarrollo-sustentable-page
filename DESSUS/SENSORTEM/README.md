# Nombre del proyecto
sensor de temperatura con arduino

## Descripción
el objetivo de este codigo expone como prender y apagar un led segun si la temperatura aumenta o disminuye de una temperatura especifica

## Objetivos de aprendizaje
Programar y simular en Arduino el encendido y apagado de un LED conectado basado en la temperatura

## Material utilizado
Enumera todos los componentes usados:
- Arduino Uno R4 WiFi
- Led
- Cables Dupont
- sensor de temperatura

# Nombre del proyecto
sensor de humedar con arduino

## Descripción
el objetivo de este codigo expone como medir la humedad

## Objetivos de aprendizaje
Montar un circuito con Arduino UNO que lea la humedad de la tierra mediante un sensor de humedad de suelo, muestre los valores en el monitor serie del Arduino IDE y use un LED como indicador visual.

## Material utilizado
Enumera todos los componentes usados:
- Arduino Uno R3
- Protoboar
- Led
- Cables Dupont
- Resistencia 220 ohms
-sensor de humedad

# Nombre del proyecto
automatización de make


# Objetivo #
Que el alumno distinga los estilos de vida y de consumo de tres generaciones de su entorno, construya sin programar una página web conectada a Make e IA para comparar sus respuestas, y formule conclusiones propias sobre la sustentabilidad de esos hábitos.

## Material utilizado

- make.com
- telefono celular
- laptop
- modulo de IA
